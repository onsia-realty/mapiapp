## 1. 대출계산기

### 1.1 기능 개요
분양가를 기준으로 LTV(담보인정비율)에 따른 대출금 계산 및 월 납입금을 산출하는 계산기

### 1.2 구현 위치
- **컴포넌트**: `src/components/calculator/LoanCalculator.tsx`
- **사용 페이지**: `src/app/category/bunyanggwon/[id]/page.tsx`

### 1.3 주요 기능

#### 입력값
| 항목 | 설명 | 기본값 | 범위 |
|-----|------|-------|------|
| 분양가 | 페이지에서 전달받는 선택된 평형의 분양가 (만원) | - | API 데이터 |
| LTV 비율 | 담보인정비율 (%) | 70% | 5% ~ 70% (5% 단위) |
| 대출기간 | 상환 기간 (년) | 20년 | 10년 / 20년 / 30년 |
| 상환방식 | 원리금균등 / 원금균등 | 원리금균등 | 2가지 |
| 생애최초 | 우대금리 적용 여부 | false | true/false |

#### 출력값
| 항목 | 설명 |
|-----|------|
| 자본금 | 분양가 - 대출금 |
| 대출금 | 분양가 × LTV% |
| 월 납입금 | 원리금균등 또는 원금균등 계산 결과 (만원) |
| 총 이자 | 전체 상환 기간 동안의 총 이자 (만원) |
| 은행별 금리 | 주요 은행 3개의 금리 및 월납입금 비교 |

### 1.4 계산 공식

#### 원리금균등상환 (Equal Principal and Interest)
```
월 납입금 = P × r × (1+r)^n / ((1+r)^n - 1)

P = 대출원금 (만원)
r = 월 이자율 (연이율 ÷ 12 ÷ 100)
n = 총 납입 개월수 (년 × 12)
```

#### 원금균등상환 (Equal Principal)
```
첫 달 납입금 = 월 원금 + 첫 달 이자
월 원금 = P ÷ n
첫 달 이자 = P × r

P = 대출원금, r = 월 이자율, n = 총 납입 개월수
(매월 납입금이 감소함 - 첫 달 기준 표시)
```

  if (amount >= 10000) {

    const man = amount % 10000;               // 만원 단위
    if (man === 0) return `${eok}억`;
    return `${eok}억 ${man.toLocaleString()}`;
  }
  return `${amount.toLocaleString()}만원`;
}

## 2. 아파트 순위

### 2.1 기능 개요
해당 매물이 위치한 지역(시군구)의 아파트 순위를 실거래가 데이터 기반으로 표시

### 2.2 구현 위치
- **API 라우트**: `src/app/api/apartment-ranking/route.ts`
- **비즈니스 로직**: `src/lib/api/apartment-ranking.ts`
- **사용 페이지**: `src/app/category/bunyanggwon/[id]/page.tsx`

### 2.3 API 명세

#### 요청
```
GET /api/apartment-ranking?address={주소}&limit={개수}
```

| 파라미터 | 필수 | 설명 | 기본값 |
|---------|-----|------|-------|
| address | ✅ | 조회 대상 주소 (시군구 추출용) | - |
| limit | ❌ | 표시할 순위 개수 | 5 |

#### 응답
```json
{
  "success": true,
  "data": {
    "regionName": "용인시 처인구",
    "period": "2026.01",
    "rankings": [...],           // 복합 점수 순위 (기본)
    "categoryRankings": {
      "composite": [...],        // 복합 점수 순위
      "tradePricePerPyeong": [...], // 매매 평당가 순위
      "jeonsePrice": [...],      // 전세 순위
      "monthlyRentPrice": [...], // 월세 순위
      "tradeVolume": [...]       // 거래량 순위
    }
  }
}
```

### 2.4 순위 카테고리 (5가지)

| 카테고리 | 설명 | 정렬 기준 |
|---------|------|----------|
| **종합** (composite) | 복합 점수 기반 | 복합점수 높은순 |
| **매매** (tradePricePerPyeong) | 매매 평당가 기준 | 평당가 높은순 |
| **전세** (jeonsePrice) | 전세 보증금 기준 | 보증금 높은순 |
| **월세** (monthlyRentPrice) | 월세 보증금 기준 | 보증금 높은순 |
| **거래량** (tradeVolume) | 총 거래건수 | 거래건수 많은순 |

### 2.5 복합 점수 계산 공식

```
복합점수 = (거래량 점수 × 0.4) + (평당가 점수 × 0.3) + (상승률 점수 × 0.3)
```

| 점수 항목 | 계산 방식 |
|----------|----------|
| 거래량 점수 | (해당 아파트 거래건수 ÷ 최대 거래건수) × 100 |
| 평당가 점수 | (해당 아파트 평당가 ÷ 최대 평당가) × 100 |
| 상승률 점수 | ((변동률 + 최대변동률) ÷ (2 × 최대변동률)) × 100 |

### 2.6 데이터 소스

#### 실거래가 API (공공데이터포털)
```
매매: https://apis.data.go.kr/1613000/RTMSDataSvcAptTrade/getRTMSDataSvcAptTrade
전월세: https://apis.data.go.kr/1613000/RTMSDataSvcAptRent/getRTMSDataSvcAptRent
```

#### 조회 기간
- **최근 3개월** 데이터 조회 (현재 월 제외)
- 예: 2026년 2월 현재 → 2025년 11월, 12월, 2026년 1월 데이터

#### 필수 파라미터
| 파라미터 | 설명 | 예시 |
|---------|------|------|
| LAWD_CD | 법정동코드 5자리 | 41461 (용인시 처인구) |
| DEAL_YMD | 거래년월 | 202601 |

## 5. 주의사항

### 대출계산기
1. 은행 금리는 **수동 업데이트** 방식 (실시간 연동 X)
2. LTV 최대 70% 제한 (규제지역 등 고려 필요 시 확장)
3. 분양가가 0 이하면 컴포넌트 렌더링하지 않음

### 아파트 순위
1. 공공데이터 API 호출 제한 있음 (일일 1000회 등)
2. 새로운 지역 추가 시 `REGION_CODE_MAP` 수동 추가 필요
3. 전월세 API는 매매 API와 별도 신청 필요 (data.go.kr)
4. XML 응답 파싱 사용 (JSON 미지원)
5. 성공 코드는 `000` (3자리)

## 6. 확장 가능 사항

1. **실시간 금리 연동**: 금융감독원 금리비교 API 연동
2. **더 많은 지역 지원**: 전국 법정동코드 매핑 테이블 확장
3. **기간 선택**: 사용자가 조회 기간 선택 가능하게
4. **캐싱**: Redis 등으로 API 응답 캐싱 (24시간 등)
5. **그래프**: 가격 추이, 거래량 추이 차트 추가
