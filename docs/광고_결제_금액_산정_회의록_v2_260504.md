## 1. 배경 — 왜 v2로 가는가

v1의 한계 3가지를 확인했고, 본 v2에서 정면 해결한다.

| v1의 한계 | 영향 | v2의 대응 |
|---|---|---|
| **4-티어 (Free/Basic/Premium/VIP) 의 선택 마비** | 가입 직전 사용자가 "어떤 게 나에게 맞지?" 고민 → 이탈 | **2-티어 (Free/Standard) 단일화** |
| **부스터 10종 과다 — 의사결정 트리 복잡** | "단순해야 추가 결제를 한다" 원칙 위배 | **3-카테고리 추가 등록만** (마피/일반/구인구직) |
| **정기결제 명시 없음 — 단발성으로 갈 우려** | 6개월차 잔존율 40% 추정 → 매출 목표 미달 | **Toss billingKey 정기결제 + 단건 병행** |

**핵심 인사이트** (실장 회의 시 도출):
- 중개사는 "AI 도구 3만원/월"에 거부감 없음 → **29,900원이 가격 앵커**
- 직방/다방/네모는 50~100만원/월이 일반 → **3만원으로 "맛보기" 미끼**
- 진짜 매출은 **추가 등록(인앱)** — 베이스는 락인 도구
- 초기 확장성 우선 → **얼리버드 100명 평생 락인**

### 2.2 50건 등록 시 건당 단가 환산

중개사 평균 매물 보유 50건 가정. 베이스 비용 ÷ 50.

| 플랫폼 / 상품 | 50건 시 월비용 | **건당 단가** |
|---|---|---|
| 직방 BASIC | 44,000원 | **880원** |
| 다방 100건 패키지 | 118,800원 | **1,188원** |
| 이실장 Mega (무제한) | 110,000원 | **2,200원** |
| 이실장 Basic (50건 + 매물전송비) | 22,000 + 50 × 1,580 = 101,000원 | **2,020원** |
| 직방 안심 | 220,000원 | **4,400원** |
| 네이버부동산 (평균) | 50 × 5,000 = 250,000원 | **5,000원** |
| 직방 VIP | 550,000원 | **11,000원** |
| **마피앱 Standard (10건만 사용)** | **29,900원** | **2,990원** |
| **마피앱 Standard (50건 = 10건+추가40)** | 29,900 + 40 × 1,000 = 69,900원 | **1,398원** |

→ **"10건만 쓰면 3만원"이 핵심 마케팅 메시지**.
→ 50건 풀 사용해도 다방 100건(1,188원)과 비슷한 수준.

### 2.3 핵심 인사이트

- **저가 시장(다방/이실장)** = 1,000~2,500원/건 → 우리 50건 풀가동 시 1,398원/건으로 진입 가능
- **고가 시장(직방 VIP)** = 6,000~11,000원/건 → 우리 마피 매물 9,900원/건이 이 영역
- **마피 매물 = 분양권 전매 = 일반 매물보다 가치 ↑** → 9,900원 정당화

## 5. Toss 정기결제 + 단건결제 병행 구조

```
┌────────────────────────────────────────────────┐
│  [정기 구독] — Toss billingKey 자동 갱신          │
│                                                │
│  사용자 ─→ /billing/plans 선택 (Standard)        │
│         ─→ Toss billing 위젯 (카드 등록)         │
│         ─→ billingKey 발급 → DB 저장 (암호화)    │
│         ─→ 매월 자동 charge (cron)               │
│         ─→ webhook → 사용량 리셋 + 알림          │
└────────────────────────────────────────────────┘
                         +
┌────────────────────────────────────────────────┐
│  [단건 결제] — 추가 등록 시 즉시 결제              │
│                                                │
│  사용자 ─→ 매물 등록 화면에서 "추가" 클릭          │
│         ─→ 정기 구독자: billingKey 재사용         │
│              → 1초 만에 결제 완료 (no popup)     │
│         ─→ 비구독자: Toss 일반 결제창              │
│              → 결제 완료 → BoosterPurchase 생성   │
└────────────────────────────────────────────────┘
```

### 분양잡과의 차이

| 항목 | 분양잡 (단발성) | 마피앱 v2 (정기결제) |
|---|---|---|
| 결제 방식 | 매월 사용자 직접 결제 (만료 시) | billingKey 자동 갱신 |
| Subscription 모델 | `expiresAt` 만료 후 다운그레이드 | `status` enum + 자동 charge cron |
| 추가 결제 | 별도 결제창 매번 | billingKey 재사용 (원클릭) |
| 6개월차 잔존율 추정 | 40% | **70%** (자동 갱신) |

### 7.1 운영 비용 추정 (월)

| **고정 운영비 합계** | **약 25만원** |

### 7.2 BEP 계산

매출 1원당 실수령 ≈ 0.971원 (Toss 2.9% 차감).
- BEP 매출 = 25만원 ÷ 0.971 ≈ **26만원/월**
- Standard 14,900원 평균 시 = **약 17명**
- Standard 29,900원 평균 시 = **약 9명**

→ **첫 달 50명 모객 시 약 4배 이익 구간 진입**.
→ 1개월차 보수 시나리오(50명 / 110만원)도 **BEP의 4배 매출**.
