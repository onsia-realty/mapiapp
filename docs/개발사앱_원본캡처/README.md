# 개발사 마피 앱 — 실기기 원본 캡처 아카이브 ("데모1")

개발사가 만든 마피 앱을 실기기(갤럭시 Z폴드, 중개사 계정 jooong@google.com)에서 화면 캡처한 원본 모음. APK가 SmartMaker 씬 클라이언트라 역분석이 불가능해, 동작 화면을 직접 캡처해 온시아 Next.js 데모 재현/회의 레퍼런스로 사용.

- 풀해상도 원본: 이 폴더의 번호순 PNG (968×2376)
- 읽기용 썸네일: `_thumbs/` (760px)
- 헬퍼: `_cap.ps1`(캡처+pull) / `_tap.ps1`(x y 탭) / `_thumb.ps1`(썸네일)
- **회의 지적사항 정리: `_회의_지적사항.md`**
