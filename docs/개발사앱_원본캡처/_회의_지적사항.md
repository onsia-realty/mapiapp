> 목적: 개발사와의 협업 회의에서 "여기까지 구현됨 / 이런 부분이 부족·오류" 를 짚기 위한 실기기 관찰 기록. 싸움 아닌 피드백용.
> 기준: 중개사 계정(jooong@google.com) 로그인, 갤럭시 Z폴드 실기기, 2026-07-03 캡처.

## 🐞 버그 / 잘못된 연결

1. **[BUG] 주변 시세 억 단위 계산 오류** — 마피 개별 매물 상세 → 주변 시세(API) 영역에서 "현재 매물 **36억 6,000만원**" 으로 표시됨. 실제는 3억 6,000만이어야 함(억 단위 자릿수 오류). 캡처: `23_maemul_detail` 계열.

2. **[BUG] "중개사 가입 / 광고안내" 버튼 링크 오류** — 더보기 → "중개사 가입 / 광고안내" 탭 시 앱 내부 광고/요금제 안내 화면이 아니라 **외부 브라우저 `m.naver.com`(네이버 메인)으로 빠짐**. 링크가 잘못 연결됨. 캡처: `91_BUG_gwanggo_naver링크오류.png`.

## ⚠️ 미구현 / 데이터 없음

- **결제 / 요금제 미구현** — 더보기(`90_more`) 및 마이페이지(`92_profile_edit` = "내 정보")에 결제·요금제 메뉴가 전혀 없음. 광고 결제/요금제 회의록(`docs/광고_결제_금액_산정_회의록`)이 있으나 앱에는 미반영.
- **마이페이지 기능 빈약** — "내 정보" 화면은 SNS 계정 로그인 / 휴대전화번호 재설정 / 로그아웃 3개뿐. 중개사 앱임에도 **내가 등록한 매물, 광고 현황, 결제 내역** 관리 화면이 없음.
- **이자만 카테고리** — 데이터 없음(빈 화면).
- **신규분양정보(청약홈)** — 데이터 없음.
- **오피스텔 / 사무실 / 상가** — 아파트와 동일 구조의 빈 지도뷰, 등록 매물 없음.

## 🧭 네비게이션 이슈

- 지도 카테고리 화면(아파트·오피스텔·사무실·상가)에서 하단 "홈" 탭과 시스템 뒤로가기가 동작하지 않음 → 헤더 좌상단 ← 만 동작.

## ✅ 정상 동작 확인된 흐름

- 홈 → 분양권 전매 목록 → 단지 상세 → 마피 매물보기(핑크버튼) → 마피 매물 리스트 → 개별 매물 상세
- 아파트(임대차) 지도 → "이 지역 매물 N개" 바텀시트 → 개별 매물 상세(실거래가 차트·상세정보·옵션·중개사·연락하기)
- 분양권 의뢰 / 이자만 의뢰 폼(입력 항목 상세)
- 관심목록(관심/최근 본), 구인구직(구인/구직·공고)
- 매물 관리 → 매물 등록(6종 카테고리) / 매물 조회(내 등록매물 목록). 분양권 전매 등록 폼: 매물정보(종류·소재지 3단·단지리스트+네이버연동·동/호수·면적·층·방향) / 거래정보(거래종류·분양가·매매가·입주예정일 즉시·지정 초순/중순/하순·협의가능) / 이미지(800×600 4:3, 2MB) / 상세정보(교통접근성·계약금1·2차·중도금·대출여부·잔금) / 매물 설명. → **입력 항목은 매우 상세하게 구현됨.**

## 📝 확인 필요 / 참고

- 분양권 등록 폼에 별도 **프리미엄(P) 입력란이 없음** — 목록/상세의 "프리미엄 +N만 / 마이너스P -N만" 뱃지가 분양가·매매가 차액으로 자동 계산되는지 확인 필요.
- 등록 폼 "네이버 단지/동 확인하기" 버튼도 외부 네이버 연동일 가능성 — 링크 동작 확인 필요.
