이 프로젝트에는 3주체가 있다:

- **온시아(주식회사 온시아)**: 사업자/플랫폼 오너. 사용자는 온시아 측 인물로 추정.
- **개발사**: 앱 제작을 외주받은 외부 개발사. `(주)온시아_앱제작대행 계약서_250814.pdf` 존재 (`onsia-web/public/요구제기서 수정/...` 내).
- **고객사**: 최종 서비스 사용자/고객 측. SNS 로그인 KEY, 알리고 KEY, OCR KEY, 결제·구독 가격 등을 제공해야 하는 주체.

**Why:** 사용자가 "개발사에서 질의한 부분", "고객사에 요청할 KEY"처럼 두 주체를 분리해서 말함. 이걸 헷갈리면 "누가 누구에게 뭘 줘야 하는지"가 뒤집혀 답변이 잘못됨.

**How to apply:**
- "개발사 질의" = 외주 개발사가 우리(온시아)에게 묻는 기술/스펙 문의. 우리가 답변 정리해서 회신.
- "고객사 제공" = 고객사가 KEY/자료를 우리에게 줘야 함. 우리가 그 목록을 정리해서 고객사에 요청.
- 이 레포(`D:\claude\onsia-mapiapp`)는 우리(온시아) 쪽 작업 디렉토리. `onsia-web/docs/개발자_전달문서_*.md`는 우리 → 개발사 방향 산출물.
