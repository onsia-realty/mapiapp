## 2. 확정된 과금 체계

### 2-1. 구독 티어 (올인원 서비스)

구독 = 매물등록 + 구인구직 + 프로필 노출 **전부 포함**

| 티어 | 월 가격 | 매물 등록 | 노출기간 | 중개사 프로필 | 구인구직 |
|------|--------|---------|---------|------------|---------|
| **Free** | 0원 | 2건 (마피1 + 일반1) | 3일 | X | X |
| **Basic** | 4,900원 | 5건 (마피/일반 합산) | 30일 | X | X |
| **Premium** | 24,900원 | 25건 (마피/일반 합산) | 30일 | 일반 노출 | 베이직 |
| **VIP** | 99,000원 | 50건 (마피/일반 합산) | 30일 | **상위 노출 + 뱃지** | **프리미엄** |

**Free 티어 조건**:
- 영업사원 또는 회사에서 체험용으로 제공하는 형태
- 마피 매물 1건 + 일반 매물 1건 = 총 2건 / 3일 노출

**핵심 차별점 (24,900원 이상)**:
- **중개사 프로필 노출 시스템**: 직방/다방 어디에도 없는 독자 기능
- 점술/운세 앱처럼 중개사가 프로필을 올리면 → 사용자가 선택해서 의뢰
- 지역별 전문 중개사, 분양권 특화 중개사 검색 가능
- 사용자가 매물을 보다가 중개사에게 직접 의뢰/매물 위탁

### 2-2. 건당 매물 추가 패키지 (구독과 별도)

구독 할당량 초과 시, 또는 구독 없이 단건 이용 시 구매

| 패키지 | 가격 | 건당 단가 | 할인율 |
|--------|------|---------|--------|
| 10건 | 30,000원 | 3,000원 | — |
| 30건 | 80,000원 | 2,667원 | 11% |
| 50건 | 125,000원 | 2,500원 | 17% |

## 3. 구인구직 과금 체계

구독과 **별개**로, 구독 없이 단건 이용 시 건당 결제
(구독자는 올인원으로 포함)

### 3-1. 공인중개사 구인 등록

노출기간: **8일** (1주 + 1일, 등록일 당일 무료)

| 상품 | 가격 | 노출 등급 |
|------|------|---------|
| 베이직 | 20,000원 | 일반 노출 |
| 프리미엄 | 50,000원 | 상위 노출 |

### 3-2. 분양상담사 구인 등록 (테마별 상품)

노출기간: **8일** (1주 + 1일, 등록일 당일 무료) / 기본은 3일

| 상품 | 가격 | 노출 등급 |
|------|------|---------|
| 헤드라인 | 150,000원 | 최상위 |
| 하이라이트 | 100,000원 | 상위 |
| MVP | 70,000원 | 중상위 |
| 프리미엄 | 50,000원 | 중위 |
| 기본 | 무료 (3일) | 일반 |

- **기본(무료)**: 명함 인증 시 누구나 1건 가능

### 3-3. 구인구직 리스트 노출 구조

공고 리스트 상위에 VIP/프리미엄 공고를 배치, **랜덤 로테이션**

```
┌─────────────────────────────┐
│ 🏆 VIP 공고 (4개, 랜덤)          │
│  [VIP A] [VIP B] [VIP C] [VIP D] │
├─────────────────────────────┤
│ ⭐ 프리미엄 공고 (4개, 랜덤)       │
│  [PR A]  [PR B]  [PR C]  [PR D]  │
├─────────────────────────────┤
│ 일반 공고 (최신순)                 │
│  - 공고 1                         │
│  - 공고 2                         │
│  - ...                            │
└─────────────────────────────┘
```

- 공인중개사 리스트(D1-02) / 분양상담사 리스트(D1-03) 각각 적용
- 같은 티어 내에서 **랜덤 로테이션** (방문마다 순서 변경)
- 각 카테고리당 **VIP 4개 + Premium 4개 = 상위 8개** 고정

## 4. 과금 구조 전체 요약

```
마피앱 과금 = 구독제(올인원) + 건당 매물 패키지 + 구인구직 단건

[구독제] ─── 올인원 (매물등록 + 프로필노출 + 구인구직)
  │
  ├─ Free     :    0원 / 2건(마피1+일반1) / 3일 / 체험용
  ├─ Basic    : 4,900원 / 5건 합산 / 30일
  ├─ Premium  : 24,900원 / 25건 합산 / 30일 / 프로필 노출 / 구인구직 베이직
  └─ VIP      : 99,000원 / 50건 합산 / 30일 / 상위 노출+뱃지 / 구인구직 프리미엄

[건당 매물 패키지] ─── 구독 할당 초과 또는 비구독자용
  │
  ├─ 10건 :  30,000원 (건당 3,000원)
  ├─ 30건 :  80,000원 (건당 2,667원)
  └─ 50건 : 125,000원 (건당 2,500원)

[구인구직 단건] ─── 구독 없이 단건 이용 시
  │
  ├─ 공인중개사: 베이직 20,000원 / 프리미엄 50,000원 (8일)
  └─ 분양상담사: 기본 무료(3일) ~ 헤드라인 150,000원 (8일)
```
